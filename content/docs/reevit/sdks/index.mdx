## Recommended Checkout Flow

Create checkout sessions on your backend, then pass only the returned session secret to your frontend SDK.

```typescript
// Backend
const session = await reevit.checkoutSessions.create(
  {
    amount: 5000,
    currency: "GHS",
    method: "mobile_money",
    country: "GH",
    metadata: { order_id: "ORD-12345" },
  },
  { idempotencyKey: "order_ORD-12345" }
);
```

```tsx
// Frontend
<ReevitCheckout
  sessionSecret={session.session_secret}
  onSuccess={(result) => console.log("Paid!", result)}
/>
```

Frontend-only checkouts using `publicKey`, `amount`, and `currency` remain supported. For live production flows, checkout sessions are recommended because the backend owns payment creation and the browser only renders the authorized session.

| Provider | Countries | Payment Methods |
|----------|-----------|-----------------|

## Quick Start

### Frontend (React)

```bash
npm install @reevit/react
```

```tsx
import { ReevitCheckout } from '@reevit/react';
import '@reevit/react/styles.css';

<ReevitCheckout
  publicKey="pfk_test_xxx.secret"
  amount={5000}
  currency="GHS"
  reference="ORD-12345"
  onSuccess={(result) => console.log('Paid!', result)}
>
  <button>Pay Now</button>
</ReevitCheckout>
```

### Backend (Node.js)

```bash
npm install @reevit/node
```

```typescript
import { Reevit } from '@reevit/node';

const client = new Reevit('pfk_live_xxx.secret', 'org_123');

const payment = await client.payments.createIntent({
  amount: 5000,
  currency: 'GHS',
  method: 'mobile_money',
  country: 'GH',
  reference: 'ORD-12345'
}, { idempotencyKey: 'order:ORD-12345' });
```

## Amounts and display

API and checkout amounts use the currency's smallest unit. The exponent varies by currency:

| Currency | API amount | Displayed amount |
|---------|------------|------------------|
| GHS | `10000` | GHS 100.00 |
| USD | `2000` | USD 20.00 |
| XOF | `5000` | XOF 5,000 |
| KWD | `12345` | KWD 12.345 |

Use the published wrapper's formatter when showing a payment result:

```typescript
import { formatAmount } from '@reevit/react';

const display = formatAmount(5000, 'XOF'); // F CFA 5,000
```

Vue and Svelte also export `formatAmount(amount, currency)`. It applies the currency exponent; dividing every amount by `100` would display XOF 5,000 as XOF 50.

## Configuration Options

| Option | Description | Default |
|--------|-------------|---------|
| `apiKey` / `publicKey` | Your API key (`pfk_...secret`) | Required |
| `orgId` | Organization ID (backend only) | Required |
| `baseUrl` / `apiBaseUrl` | API base URL | `https://api.reevit.io` |
| `timeout` | Request timeout | `30s` |
