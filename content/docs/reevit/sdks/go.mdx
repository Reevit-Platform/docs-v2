# Go SDK

[![GitHub](https://img.shields.io/badge/GitHub-Reevit--Platform%2Fgo-blue)](https://github.com/Reevit-Platform/go-sdk)

The official Go SDK for the Reevit payment orchestration platform.

Guarded writes shown here require an idempotency key, even when the SDK argument is optional in its type signature. Keep one key per logical order or operation, reuse it with the identical payload on retries, and use a new key for a new operation. A payment reference alone does not set the header.

## Installation

```bash
go get github.com/Reevit-Platform/go-sdk@v0.11.0
```

## Quick Start

```go
package main

import (
    "context"
    "fmt"
    reevit "github.com/Reevit-Platform/go-sdk"
)

func main() {
    client := reevit.NewClient("pfk_live_xxx.secret", "org_123")

    intent, err := client.Payments.CreateIntent(context.Background(), &reevit.PaymentIntentRequest{
        Amount:     5000,
        Currency:   "GHS",
        Method:     "mobile_money",
        Country:    "GH",
        CustomerID: "cust_456",
        Reference:  "ORD-12345",
        Metadata: map[string]interface{}{
            "order_id": "12345",
        },
    }, reevit.WithIdempotencyKey("order:ORD-12345"))
    if err != nil {
        panic(err)
    }

    fmt.Printf("Payment ID: %s, Status: %s\n", intent.ID, intent.Status)
}
```

## Checkout Sessions

Use checkout sessions when a browser SDK will render the payment UI. Your backend creates the session, then your frontend receives only `session.SessionSecret`.

```go
session, err := client.CheckoutSessions.Create(ctx, &reevit.PaymentIntentRequest{
    Amount:   5000,
    Currency: "GHS",
    Method:   "mobile_money",
    Country:  "GH",
    Metadata: map[string]interface{}{
        "order_id": "ORD-12345",
    },
}, reevit.WithIdempotencyKey("order_ORD-12345"))
if err != nil {
    log.Fatal(err)
}

fmt.Println(session.SessionSecret)
```

## Payments

### Create Payment Intent

```go
intent, err := client.Payments.CreateIntent(ctx, &reevit.PaymentIntentRequest{
    Amount:     10000,
    Currency:   "GHS",
    Method:     "mobile_money",
    Country:    "GH",
    CustomerID: "cust_123",
    Reference:  "ORD-2024-001",
    Metadata: map[string]interface{}{
        "order_id": "ORD-2024-001",
    },
}, reevit.WithIdempotencyKey("order:ORD-2024-001"))
```

### Get Payment

```go
payment, err := client.Payments.Get(ctx, "pay_abc123")
if err != nil {
    log.Fatal(err)
}
fmt.Printf("Status: %s, Amount: %d\n", payment.Status, payment.Amount)
```

### List Payments

```go
payments, err := client.Payments.List(ctx, 50, 0) // limit, offset
for _, p := range payments {
    fmt.Printf("%s: %s\n", p.ID, p.Status)
}
```


## Connections

### Create Connection

```go
conn, err := client.Connections.Create(ctx, &reevit.ConnectionRequest{
    Provider: "paystack",
    Mode:     "live",
    Credentials: map[string]interface{}{
        "secret_key": "sk_live_xxx",
    },
    Labels: []string{"nigeria", "primary"},

        CountryPreference: []string{"NG"},
        MethodBias: map[string]string{

        },

```

```go
connections, err := client.Connections.List(ctx)
```

## Webhook Verification

```go
import (
    "crypto/hmac"
    "crypto/sha256"
    "encoding/hex"
    "encoding/json"
    "io"
    "log"
    "net/http"
)

func handleWebhook(w http.ResponseWriter, r *http.Request) {
    body, _ := io.ReadAll(r.Body)
    signature := r.Header.Get("X-Reevit-Signature")

    mac := hmac.New(sha256.New, []byte(webhookSecret))
    mac.Write(body)
    expected := "sha256=" + hex.EncodeToString(mac.Sum(nil))

    if !hmac.Equal([]byte(signature), []byte(expected)) {
        http.Error(w, "Invalid signature", 401)
        return
    }

    var event map[string]interface{}
    json.Unmarshal(body, &event)

    // The discriminator is "event"; the outcome is in data.status.
    switch event["event"] {
    case "payment.updated":
        data, _ := event["data"].(map[string]interface{})
        switch data["status"] {
        case "succeeded":
            // Handle success
            log.Printf("Payment succeeded: %v", data)
        case "failed":
            // Handle failure
        }
    }
    
    w.WriteHeader(200)
}
```

## Error Handling

```go
intent, err := client.Payments.CreateIntent(ctx, &reevit.PaymentIntentRequest{
    Amount:    5000,
    Currency:  "GHS",
    Method:    "mobile_money",
    Country:   "GH",
    Reference: "ORD-12345",
}, reevit.WithIdempotencyKey("order:ORD-12345"))
if err != nil {
    if apiErr, ok := err.(*reevit.APIError); ok {
        fmt.Printf("API Error: %s (code: %s)\n", apiErr.Message, apiErr.Code)
        fmt.Printf("HTTP Status: %d\n", apiErr.StatusCode)
    } else {
        fmt.Printf("Error: %v\n", err)
    }
    return
}
```
