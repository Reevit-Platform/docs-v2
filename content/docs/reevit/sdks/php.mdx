# PHP SDK

[![GitHub](https://img.shields.io/badge/GitHub-Reevit--Platform%2Fphp-blue)](https://github.com/Reevit-Platform/php-sdk)

The official PHP SDK for the Reevit payment orchestration platform.

Guarded writes shown here require an idempotency key, even when the SDK argument is optional in its type signature. Keep one key per logical order or operation, reuse it with the identical payload on retries, and use a new key for a new operation. A payment reference alone does not set the header.

## Installation

```bash
composer require reevit/reevit-php
```

## Quick Start

```php
<?php
require_once 'vendor/autoload.php';

use Reevit\Reevit;

$client = new Reevit('pfk_live_xxx.secret', 'org_123');

// Create payment intent
$intent = $client->payments->createIntent([
    'amount' => 5000,
    'currency' => 'GHS',
    'method' => 'mobile_money',
    'country' => 'GH',
    'customer_id' => 'cust_456',
    'reference' => 'ORD-12345',
    'metadata' => [
        'order_id' => '12345',
    ],
], 'order:ORD-12345');

echo "Payment ID: {$intent['id']}, Status: {$intent['status']}\n";
```

## Checkout Sessions

Use checkout sessions when a browser SDK will render the payment UI. Your backend creates the session, then your frontend receives only `$session['session_secret']`.

```php
$session = $client->checkoutSessions->create([
    'amount' => 5000,
    'currency' => 'GHS',
    'method' => 'mobile_money',
    'country' => 'GH',
    'metadata' => [
        'order_id' => 'ORD-12345',
    ],
], 'order_ORD-12345');

echo $session['session_secret'];
```

## Payments

### Create Payment Intent

```php
$intent = $client->payments->createIntent([
    'amount' => 10000,
    'currency' => 'GHS',
    'method' => 'mobile_money',
    'country' => 'GH',
    'customer_id' => 'cust_123',
    'reference' => 'ORD-2024-001',
    'metadata' => [
        'order_id' => 'ORD-2024-001',
    ],
], 'order:ORD-2024-001');
```

### Get Payment

```php
$payment = $client->payments->get('pay_abc123');
echo "Status: {$payment['status']}\n";
```

### List Payments

```php
$payments = $client->payments->list(50, 0);
foreach ($payments as $payment) {
    echo "{$payment['id']}: {$payment['status']}\n";
}
```

### Refund Payment

Choose either a full or partial refund. Each separate refund request needs its own stable operation key.

With the published PHP SDK 0.3.0, include a reason for a full refund so the request body is a JSON object. Keep the amount `null` to request the full refund.

```php
// Full refund
$refund = $client->payments->refund('pay_abc123', null, 'Customer requested', 'refund:pay_abc123:full');

// Partial refund
$refund = $client->payments->refund(
    'pay_abc123',
    2500,
    'Customer requested',
    'refund:pay_abc123:partial_1'
);
```


## Webhook Verification

```php
<?php
$payload = file_get_contents('php://input');
$signature = $_SERVER['HTTP_X_REEVIT_SIGNATURE'] ?? '';
$webhookSecret = getenv('REEVIT_WEBHOOK_SECRET');

$expected = 'sha256=' . hash_hmac('sha256', $payload, $webhookSecret);
if (!hash_equals($expected, $signature)) {
    http_response_code(401);
    exit('Invalid signature');
}

$event = json_decode($payload, true);

switch ($event['event']) {
    case 'payment.updated':
        if ($event['data']['status'] === 'succeeded') {
            // Handle success
        }
        break;
}

http_response_code(200);
echo 'OK';
```

### Laravel Webhook Handler

```php
// routes/api.php
Route::post('/webhooks/reevit', [WebhookController::class, 'handle']);

// app/Http/Controllers/WebhookController.php
namespace App\Http\Controllers;

use Illuminate\Http\Request;
class WebhookController extends Controller
{
    public function handle(Request $request)
    {
        $payload = $request->getContent();
        $signature = $request->header('X-Reevit-Signature', '');
        $secret = config('services.reevit.webhook_secret');
        
        $expected = 'sha256=' . hash_hmac('sha256', $payload, $secret);
        if (!hash_equals($expected, $signature)) {
            return response()->json(['error' => 'Invalid signature'], 401);
        }
        
        $event = $request->all();
        
        switch ($event['event']) {
            case 'payment.updated':
                if ($event['data']['status'] === 'succeeded') {
                    $orderId = $event['data']['metadata']['order_id'] ?? null;
                    // Fulfill order
                }
                break;
        }
        
        return response()->json(['received' => true]);
    }
}
```

## Error Handling

```php
try {
    $payment = $client->payments->createIntent([
        'amount' => 5000,
        'currency' => 'GHS',
        'method' => 'mobile_money',
        'country' => 'GH',
    ], 'order:ORD-12345');
} catch (\Reevit\ReevitApiException $e) {
    echo "API Error: {$e->getMessage()}\n";
    echo "Code: {$e->getErrorCode()}\n";
    echo "HTTP Status: {$e->getStatus()}\n";
} catch (\Exception $e) {
    echo "Error: {$e->getMessage()}\n";
}
```
