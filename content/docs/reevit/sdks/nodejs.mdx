# Node.js SDK

[![npm version](https://img.shields.io/npm/v/@reevit/node.svg)](https://www.npmjs.com/package/@reevit/node)
[![GitHub](https://img.shields.io/badge/GitHub-Reevit--Platform%2Fnode-sdk-blue)](https://github.com/Reevit-Platform/node-sdk)

The official Node.js/TypeScript SDK for the Reevit payment orchestration platform.

Guarded writes shown here require an idempotency key, even when the SDK argument is optional in its type signature. Keep one key per logical order or operation, reuse it with the identical payload on retries, and use a new key for a new operation. A payment reference alone does not set the header.

## Installation

```bash
npm install @reevit/node
# or
yarn add @reevit/node
# or
pnpm add @reevit/node
```

## Quick Start

```typescript
import { Reevit } from '@reevit/node';

// Initialize the client
const reevit = new Reevit(
  'pfk_live_your_api_key.secret',  // Your API key
  'org_your_org_id'          // Your organization ID
);

// Create a payment
const payment = await reevit.payments.createIntent({
  amount: 5000,      // 50.00 GHS (amount in smallest currency unit)
  currency: 'GHS',
  method: 'mobile_money',
  country: 'GH',
  customer_id: 'cust_123',
  reference: 'ORD-12345'
}, { idempotencyKey: 'order:ORD-12345' });

console.log('Payment ID:', payment.id);
console.log('Status:', payment.status);
```

## Checkout Sessions

Use checkout sessions when a browser SDK will render the payment UI. Your backend creates the session with a private key, then your frontend receives only `session.session_secret`.

```typescript
const session = await reevit.checkoutSessions.create(
  {
    amount: 5000,
    currency: 'GHS',
    method: 'mobile_money',
    country: 'GH',
    customer_id: 'cust_123',
    metadata: { order_id: 'ORD-12345' },
  },
  { idempotencyKey: 'order_ORD-12345' }
);

console.log(session.session_secret);
```

```tsx
<ReevitCheckout sessionSecret={session.session_secret} />
```

## Payments

### Create Payment Intent

```typescript
const payment = await reevit.payments.createIntent({
  amount: 10000,           // 100.00 in smallest currency unit
  currency: 'GHS',         // Currency code (GHS, NGN, KES, USD)
  method: 'mobile_money',          // Payment method
  country: 'GH',           // ISO country code
  customer_id: 'cust_123', // Optional: Your customer reference
  reference: 'order_456',  // Optional: External reference
  metadata: {              // Optional: Custom metadata
    product: 'Premium Plan',
    order_id: 'order_456'
  }
}, { idempotencyKey: 'order:order_456' });
```

### Payment Methods by Country

| Country | Code | Supported Methods |
|---------|------|-------------------|
| Ghana | `GH` | `mobile_money`, `card`, `bank_transfer` |
| Nigeria | `NG` | `card`, `bank_transfer` |
| Kenya | `KE` | `mobile_money`, `card` |

### Get Payment

```typescript
const payment = await reevit.payments.get('pay_abc123');

console.log('Payment Details:', {
  id: payment.id,
  status: payment.status,
  amount: payment.amount,
  currency: payment.currency,
  fee: payment.fee_amount,
  provider: payment.provider,
});
```

### List Payments

```typescript
// Basic listing (default: 50 payments)
const payments = await reevit.payments.list();

// With pagination
const page1 = await reevit.payments.list(10, 0);   // First 10
const page2 = await reevit.payments.list(10, 10);  // Next 10
```

### Refund Payment

Choose either a full or partial refund. Each separate refund request needs its own stable operation key.

```typescript
// Full refund
const fullRefund = await reevit.payments.refund('pay_abc123', undefined, undefined, { idempotencyKey: 'refund:pay_abc123:full' });

// Partial refund
const partialRefund = await reevit.payments.refund(
  'pay_abc123',
  2500,                    // Refund 25.00
  'Customer requested',    // Reason (optional)
  { idempotencyKey: 'refund:pay_abc123:partial_1' }
);
```

## Error Handling

The SDK throws `ReevitAPIError` for API and network failures. Use `recoverable` to decide whether to show retry UI.

```typescript
import { ReevitAPIError } from '@reevit/node';

try {
  await reevit.checkoutSessions.create(payload, { idempotencyKey: 'order_123' });
} catch (error) {
  if (error instanceof ReevitAPIError) {
    console.error(error.code, error.status, error.requestId);
    if (error.recoverable) {
      // show retry action
    }
  }
  throw error;
}
```

## Connections

Manage your PSP integrations.

### Create Connection

```typescript
// Paystack Connection
const paystackConnection = await reevit.connections.create({
  provider: 'paystack',
  mode: 'live',
  credentials: {
    secret_key: 'sk_live_xxx'
  },
  labels: ['nigeria', 'primary'],
  routing_hints: {
    country_preference: ['NG'],
    method_bias: { card: 'high', bank_transfer: 'medium' },
    fallback_only: false
  }
}, { idempotencyKey: 'connection:create:paystack:live' });
```

### List Connections

```typescript
const connections = await reevit.connections.list();

connections.forEach(conn => {
  console.log(`${conn.provider} (${conn.mode}): ${conn.status}`);
});
```

const isValid = await reevit.connections.test({

## Fraud Protection

```typescript
// Get current policy
const policy = await reevit.fraud.get();

// The published Node SDK's fraud.update has no request-options argument.
// Use REST to send the required operation key.
const response = await fetch(new URL('/v1/policies/fraud', process.env.REEVIT_BASE_URL ?? 'https://api.reevit.io'), {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'X-Reevit-Key': process.env.REEVIT_API_KEY!,
    'X-Org-Id': process.env.REEVIT_ORG_ID!,
    'Idempotency-Key': 'fraud-policy:update:revision_2',
  },
  body: JSON.stringify({
    max_amount: 500000,
    blocked_bins: ['123456'],
    allowed_bins: [],
    velocity_max_per_minute: 10,
  }),
});
if (!response.ok) throw new Error(`Reevit request failed: ${response.status}`);
const updatedPolicy = await response.json();
```

## Webhook Verification

```typescript
import crypto from 'crypto';

app.post('/webhooks/reevit', express.raw({ type: 'application/json' }), (req, res) => {
  const signature = req.headers['x-reevit-signature'];
  const expected = 'sha256=' + crypto
    .createHmac('sha256', webhookSecret)
    .update(req.body)
    .digest('hex');

  if (!signature || signature.length !== expected.length ||
      !crypto.timingSafeEqual(Buffer.from(signature), Buffer.from(expected))) {
    return res.status(401).send('Invalid signature');
  }

  const event = JSON.parse(req.body.toString('utf8'));

  // The discriminator is `event`; terminal states arrive as
  // `payment.updated` with the outcome in `data.status`.
  switch (event.event) {
    case 'payment.updated':
      if (event.data.status === 'succeeded') {
        // Handle success
      } else if (event.data.status === 'failed') {
        // Handle failure
      }
      break;
  }

  res.status(200).send('OK');
});
```

import { ReevitAPIError } from '@reevit/node';

try {
